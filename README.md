## About

Follows the Futurar `[APP_NAME]-mcp` naming convention, aligning every app in
the Frappe/ERPNext ecosystem with Model Context Protocol (MCP) integrations,
agentic workflows, and extended automation services.

Formerly: **Education**

Domain operations will be exposed as MCP tools so AI assistants and agents can
drive this app's workflows directly.
